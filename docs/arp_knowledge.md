# ARP 协议与 ARP 欺骗知识库

## 1. 什么是 ARP 协议？
ARP（Address Resolution Protocol，地址解析协议）是用于根据 IP 地址获取物理地址（MAC 地址）的一个 TCP/IP 协议。

### 工作原理：
1. **ARP 请求**：当主机 A 要向主机 B 发送数据时，会先检查自己的 ARP 缓存表。如果没有主机 B 的 MAC 地址，主机 A 就会发送一个广播包（ARP Request），询问：“谁的 IP 是 192.168.1.x？请告诉我你的 MAC 地址。”
2. **ARP 响应**：局域网内所有主机都会收到这个广播，但只有主机 B 会回复一个单播包（ARP Reply）：“我的 IP 是 192.168.1.x，我的 MAC 地址是 XX:XX:XX:XX:XX:XX。”
3. **缓存**：主机 A 收到回复后，会将该 IP 与 MAC 的对应关系存入 ARP 缓存表中，以便下次直接使用。

## 2. 什么是 ARP 欺骗（ARP Poisoning）？
ARP 协议设计于早期，缺乏安全验证机制。它默认“信任所有收到的 ARP 响应”。

### 欺骗过程：
1. **攻击者（主机 C）** 持续向 **目标（主机 A）** 发送伪造的 ARP 响应，声称：“我是网关，我的 MAC 地址是攻击者的 MAC。”
2. **同时**，攻击者向 **网关** 发送伪造的 ARP 响应，声称：“我是主机 A，我的 MAC 地址是攻击者的 MAC。”
3. **结果**：主机 A 和网关的 ARP 缓存表都被污染。主机 A 发往网关的所有流量都会先发给攻击者，网关发往主机 A 的流量也会先经由攻击者。

## 3. ARP 攻击的常见后果
- **中间人攻击 (MITM)**：攻击者可以拦截、截获甚至修改通信内容。
- **拒绝服务 (DoS)**：攻击者拦截流量后直接丢弃，导致目标无法上网。

## 4. 如何防范？
- **静态 ARP 绑定**：手动在电脑和路由器上绑定 IP 与 MAC。
- **DAI (Dynamic ARP Inspection)**：在企业级交换机上启用动态 ARP 检测。
- **安全软件**：使用防火墙或专业的 ARP 防护工具。
